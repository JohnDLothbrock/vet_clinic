# Veterinary Clinic Management System

Veterinary clinic management application built with:

- FastAPI
- SQL Server
- PyODBC
- React
- Python

## Features

- Owner Management
- Pet Management
- Appointment Management
- Dashboard Statistics
- REST API
- Swagger Documentation

## Run Backend

```bash
uvicorn main_api:app --reload
```

## Run Frontend

```bash
npm run dev
```
